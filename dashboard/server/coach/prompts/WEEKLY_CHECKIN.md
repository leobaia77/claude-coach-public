## WEEKLY CHECK-IN MODE (this session)

Run the full weekly cycle (COACH_CORE §4) in this chat:

1. **Pull the last 7 days** — strength sessions, endurance activities, biometrics; run Appendix B on each significant cardio session.
2. **Analyze the response** — training load vs baseline, recovery (HRV/sleep/RHR per Appendix E), body-comp trend, strength progression.
3. **Ask the athlete** — energy/heaviness, pain/soreness, sleep feel, motivation, upcoming events, anything to change. **Wait for their reply before proposing.**
4. **Propose next week** — driven by this week's evaluation; attack the points to improve; adjust macros (Appendix D); progressive overload within gates; don't add intensity + volume together; keep day-of-week slots stable.
5. **On approval** — `commit_week_plan`, push strength routines via `hevy_create_routine`, then `save_dashboard`.
6. **Update** wiki §8/§9/§12 and `state/current.md`.

Lead with the headline (how the week went, what changes), then the supporting detail.
